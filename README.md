# Fourseasquant

Fourseasquant 是仅在本机运行的 A 股市场与策略日频复盘应用。当前切片提供 React（网页界面框架）桌面仪表盘骨架、FastAPI（Python 接口框架）健康接口和 SQLite（本地数据库）初始化。

## 环境准备

项目依赖必须安装到项目目录，不要写入 macOS 系统 Python：

```zsh
uv sync
npm install
```

## 启动

```zsh
npm run dev
```

启动后访问：

- 仪表盘：`http://127.0.0.1:5173``
- 后端健康接口：`http://127.0.0.1:8000/api/health`

开发进程会初始化本地数据库。按 `Control-C` 可同时停止前端和后端。

## 每日快照

在仪表盘的“每日快照”区域选择目标日期，再点击“运行目标日期任务”。当前版本使用确定性模拟适配器生成快照，页面会分别显示目标日期、实际数据日期、任务状态和最近更新时间。

快照中的沪深主板市场概览独立展示上证指数、深证成指、创业板指、沪深 300、市场广度、涨跌停与连板、成交活跃度及近 20 日新高新低。股票统计统一排除科创板、创业板、ST（特别处理）、停牌、退市整理期和上市未满 20 个交易日的新股；界面不生成综合情绪分数或主观市场判断。

行业板块与概念板块使用同一份已发布快照，可分别查看涨幅前十、跌幅前十和同源热力图。A 股行情颜色遵循红涨绿跌，所有板块模拟结果均显示“演示数据”标记。

模拟策略适配器生成最近三年的确定性日频历史，并展示当日策略、沪深 300 基准和超额收益，策略/基准/超额净值曲线，回撤曲线，以及累计收益、年化收益、最大回撤、夏普比率和胜率。默认显示策略成立以来，可切换近一年和近三个月，曲线与统计同步切换；所有结果持续标记为演示数据。当前模拟交易日历按上海证券交易所公布的 2023—2026 年休市安排排除周末及节假日休市日期。

每日复盘笔记和自定义标签绑定实际数据日期并独立持久化，不存放在可重新生成的市场与策略快照中。页面明确显示尚无笔记、保存中、保存成功和保存失败状态。

演示组合固定生成 24 只模拟持仓，并提供当前持仓、当日交易和个股收益贡献表格。发布前会校验持仓唯一性、权重合计、交易日期及收益贡献汇总，页面支持按权重、持有收益和当日贡献排序，遵循红涨绿跌。

当前模拟阶段不需要 Tushare Token（Tushare 访问令牌）。只有后续明确选择 Tushare 作为真实市场数据源并开始实现相应适配器时，才需要在本机安全环境中配置令牌；令牌不得写入代码、网页、日志或 Git。

页面右上角的设置面板可管理自动更新时间、默认策略基准、已注册的数据适配器和新股排除交易日。设置保存在本机数据库中，重启后仍然生效，并从下一次每日任务开始影响市场范围和策略基准；面板及接口只暴露非敏感配置。

每日任务按市场准备、策略运行、输出校验和事务发布四个阶段记录状态。任一阶段失败时，网站继续展示最近一次完整成功快照，并在页面顶部显示失败阶段、时间与重试按钮；最近任务摘要可在网站内查看。详细结构化日志默认轮转保存在 `logs/tasks.jsonl`，日志只记录任务标识、阶段、时间和异常类型，不记录访问令牌等秘密。

## 检查与测试

```zsh
npm run typecheck
npm test
```

`npm test` 会先构建前端，再使用独立临时数据库通过公开 HTTP 接口验证后端行为，最后复用本机 Google Chrome（谷歌浏览器）执行页面操作测试。

## 生产式本机预览

```zsh
npm run build
uv run uvicorn --app-dir backend fourseasquant.main:app --host 127.0.0.1 --port 8000
```

然后访问 `http://127.0.0.1:8000`。服务只绑定本机回环地址，不对局域网或公网开放。
