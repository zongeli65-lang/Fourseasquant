# Fourseasquant

Fourseasquant 是仅在本机运行的 A 股市场与策略日频复盘应用。当前切片提供 React（网页界面框架）桌面仪表盘骨架、FastAPI（Python 接口框架）健康接口和 SQLite（本地数据库）初始化。

## 环境准备

项目依赖必须安装到项目目录，不要写入 macOS 系统 Python：

```zsh
uv sync
npm install
```

## 启动

```zsh
npm run dev
```

启动后访问：

- 仪表盘：`http://127.0.0.1:5173`
- 后端健康接口：`http://127.0.0.1:8000/api/health`

开发进程会初始化本地数据库。按 `Control-C` 可同时停止前端和后端。

网站采用多页面桌面工作台结构：总览、市场、行情、策略、基本面和任务分别使用
`/overview`、`/market`、`/quotes`、`/strategy`、`/fundamentals` 和 `/tasks`。根地址默认进入总览，页面切换与刷新会保留目标日期和所选股票。完整的品牌、布局和交互约束见[前端设计系统](docs/FRONTEND_DESIGN_SYSTEM.md)。

## 每日快照

在仪表盘的“每日快照”区域选择目标日期，再点击“运行目标日期任务”。页面会分别显示目标日期、实际数据日期、任务状态和最近更新时间。仓库仍保留确定性模拟器作为策略输出契约的测试夹具；它不是正式行情源，不能覆盖或伪装成 AKShare 真实数据。

## AKShare 真实行情

正式行情源仅使用 AKShare（A 股数据接口库），不接入 Tushare。当前生产采集链路组合使用新浪全市场快照、沪深证券名录和新浪沪深 300 日线，避开本机实测不稳定的东方财富实时接口。采集结果统一筛选沪深主板，排除 ST（特别处理）、退市名称、停牌和上市未满设置交易日数的新股。

服务启动后，可通过本机接口采集目标日对应的最近交易日真实行情：

```zsh
curl -X POST http://127.0.0.1:8000/api/market-data/daily \
  -H 'Content-Type: application/json' \
  -d '{"target_date":"2026-07-22"}'
```

完整批次通过 Pydantic（数据模型校验库）校验后才会写入 `data/fourseasquant.db` 的 `market_fact_snapshots` 表。相同交易日和相同内容按 SHA-256（内容哈希算法）去重；上游修订会追加新版本，旧版本永久保留。网络失败、空股票池或字段异常不会写入残缺批次。

全市场快照只允许保存为 AKShare 当前最新交易日；接口会拒绝把最新价格改标签为历史行情。最近三年的历史初始化需要走 AKShare 的逐股历史接口并建立本机缓存，不能复用该最新快照接口。

过去一年真实日频数据使用 AKShare 新浪个股日线接口，价格、成交量和成交额均直接来自上游字段，不使用价格乘成交量等估算值。运行命令：

```zsh
npm run data:history-year
```

导入器默认使用 2 个受控并发连接，每只股票最多重试 3 次。逐股数据与完成标记在同一 SQLite（本地数据库）事务中提交；中断后重新执行同一命令会跳过已完成股票。只有全部股票采集完成且每个交易日都有合格个股时，才会生成日级完整结果。

2026-07-23 的本机实测已完成三市场最近一年正式窗口 2025-07-24 至 2026-07-23，并保留从 2025-04-25 开始的 60 个交易日预热区间：4996 只清单证券的不复权与前复权采集均处理成功，失败 0 只，形成 242 个正式完整交易日。前复权缓存覆盖 4982 只有合格历史的证券和 1,485,873 条事实；技术评分永久保存 1,193,306 条结果。五个指数各保留 302 个交易日。技术分项越界记录、非法价格或成交量、重复日期与代码组合均为 0 条。

网站通过 `GET /api/market-data/dashboard?target_date=YYYY-MM-DD` 读取真实行情仪表盘。请求非交易日或尚未收盘的日期时，会自动回退到不晚于目标日的最近完整交易日。页面展示沪深 300 收盘走势、沪深主板成交额走势、上涨与下跌家数、个股涨跌幅分布、涨跌幅排行榜，以及成交额前 100 只股票热力图；A 股颜色遵循红涨绿跌。接口使用预聚合日表和目标日明细，避免把全部历史明细发送到浏览器。

## 日 K 线浏览

日 K 浏览器覆盖当前最新完整交易日仍符合规则的沪深主板、创业板和科创板股票，以及上证指数、深证成指、沪深 300、创业板指和科创 50。默认打开上证指数；股票可按六位代码或中文名称搜索，也可从排行榜、热力图、技术评分、持仓、交易和收益贡献表直接进入。图表显示日 K、日成交量和 Wilder RSI(14)（威尔德相对强弱指标），标出 30、50、70 三条参考线，并支持十字光标、滚轮缩放、拖动平移和回到最近交易日。

股票默认显示前复权，可切换不复权；原始日线永久保留，前复权数据通过独立版本发布。页面切换到历史复盘日期时，K 线严格截止该日期，不展示未来行情。真实策略交易接入后，每笔买入和卖出分别以 B/S 标记；演示策略不会生成交易标记。

首次准备最近一年完整 K 线数据运行：

```zsh
npm run data:candles-year
```

该命令会补齐股票不复权、股票前复权和五个指数。只有同一交易日的所有数据完整且股票集合一致时，才会发布到网页；中断后可重跑并从已完成股票继续。

三市场个股技术评分的首次初始化运行：

```zsh
npm run data:technical-init
```

该命令读取沪深主板、创业板、科创板最近一年正式行情，并额外获取 60 个交易日作为 EMA（指数移动平均）、ATR（平均真实波幅）和极值结构的预热期。评分按算法版本永久保存；同一版本的参数不可修改，参数调整必须发布新版本。每日 16:30 任务会先暂存新评分，只有行情、策略和校验全部成功时才与每日快照在同一事务中激活。

快照中的沪深主板市场概览独立展示上证指数、深证成指、创业板指、沪深 300、市场广度、涨跌停与连板、成交活跃度及近 20 日新高新低。股票统计统一排除科创板、创业板、ST（特别处理）、停牌、退市整理期和上市未满 20 个交易日的新股；界面不生成综合情绪分数或主观市场判断。

板块及其成员未来由独立基本面分析模块根据财报、公司与行业研究、简报和快报认定；个股技术评分不依赖板块归属，板块技术强度只由确认后的技术龙头代表，不直接导入第三方板块指数涨跌幅。在收到完整、带版本和生效日期的基本面成员快照前，网站不会展示模拟板块龙头或伪造板块排行。A 股行情颜色遵循红涨绿跌。

个人基本面模块已经完成第一批机械化内核，包括林奇核心数据、主营业务毛利润贡献、流通市值百分位、内部人士与公司资本行为信号，以及东方财富股吧和雪球的讨论聚合。它不调用 Agent（智能体），也不生成专业研报式总分。运行 AKShare 新浪行业、概念板块及成分股导入：

```zsh
npm run data:fundamental-boards
```

导入时使用最新正式行情股票集合过滤成员，只保留沪深主板、创业板和科创板，自动排除 ST（特别处理）、退市、北交所及不在当日正式股票集合中的代码。候选板块仅用于发现股票，不直接成为正式策略板块。

结构化月度财务输入和每日讨论输入分别使用：

```zsh
npm run fundamental:monthly -- /绝对路径/monthly-input.json
npm run fundamental:sentiment -- /绝对路径/discussion-input.json
```

继续开发前请阅读[个人基本面模块工程交接](docs/FUNDAMENTAL_ENGINEERING_HANDOFF.md)和[个人基本面机械规则](docs/FUNDAMENTAL_MECHANICAL_RULES.md)。

基本面已发布快照可以在 `/fundamentals` 页面查看。页面提供候选板块筛选、股票代码或名称搜索、后端原始指标排序、个股四支柱详情、最近十二个月度快照和最近三十天舆情趋势。只读接口统一位于 `/api/fundamentals`，请求不会触发爬虫或重新计算。缺失值分别显示为“不适用”“数据不足”“无法确定”或“等待另一平台数据”，不会显示为 0，也不会生成基本面总分。

模拟策略适配器生成最近三年的确定性日频历史，并展示当日策略、沪深 300 基准和超额收益，策略/基准/超额净值曲线，回撤曲线，以及累计收益、年化收益、最大回撤、夏普比率和胜率。默认显示策略成立以来，可切换近一年和近三个月，曲线与统计同步切换；所有结果持续标记为演示数据。当前模拟交易日历按上海证券交易所公布的 2023—2026 年休市安排排除周末及节假日休市日期。

每日复盘笔记和自定义标签绑定实际数据日期并独立持久化，不存放在可重新生成的市场与策略快照中。页面明确显示尚无笔记、保存中、保存成功和保存失败状态。

演示组合固定生成 24 只模拟持仓，并提供当前持仓、当日交易和个股收益贡献表格。发布前会校验持仓唯一性、权重合计、交易日期及收益贡献汇总，页面支持按权重、持有收益和当日贡献排序，遵循红涨绿跌。

本项目不使用 Tushare，因此不需要 Tushare Token（Tushare 访问令牌）。任何密码、访问令牌或其他秘密都不得写入代码、网页、日志或 Git。

页面右上角的设置面板可管理自动更新时间、默认策略基准、已注册的数据适配器和新股排除交易日。设置保存在本机数据库中，重启后仍然生效，并从下一次每日任务开始影响市场范围和策略基准；面板及接口只暴露非敏感配置。

每日任务按市场准备、策略运行、输出校验和事务发布四个阶段记录状态。市场准备阶段同时更新股票与五个指数 K 线并暂存个股技术评分，完整校验通过后才将技术评分与策略快照原子发布。任一阶段失败时，网站继续展示最近一次完整成功快照，并在页面顶部显示失败阶段、时间与重试按钮；最近任务摘要可在网站内查看。详细结构化日志默认轮转保存在 `logs/tasks.jsonl`，日志只记录任务标识、阶段、时间和异常类型，不记录访问令牌等秘密。

设置面板中的“日期范围补算”会先按交易日历预览实际处理数量，确认后逐日复用每日任务流水线。非交易日自动跳过，每个交易日独立发布并记录成功或失败；重复补算只替换计算快照，不修改该日期已有的人工笔记与标签。单次范围限制为约三年，适合初始化最近三年历史。

macOS 日常自动化由 LaunchAgent（用户后台启动代理）在设置的北京时间触发。定时入口会跳过非交易日和已有成功快照，网站启动时会补跑最近缺失交易日，成功与失败均发送通知且通知故障不会影响业务快照。安装、启停、立即运行与排错命令见 [本机自动化维护说明](docs/AUTOMATION.md)。

## 检查与测试

```zsh
npm run typecheck
npm test
```

`npm test` 会先构建前端，再使用独立临时数据库通过公开 HTTP 接口验证后端行为，最后复用本机 Google Chrome（谷歌浏览器）执行页面操作测试。

## 生产式本机预览

```zsh
npm run build
uv run uvicorn --app-dir backend fourseasquant.main:app --host 127.0.0.1 --port 8000
```

然后访问 `http://127.0.0.1:8000`。服务只绑定本机回环地址，不对局域网或公网开放。
