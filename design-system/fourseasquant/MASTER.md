# Fourseasquant 设计系统主文件

> 页面开发前先检查 `design-system/fourseasquant/pages/<页面名称>.md`。如果存在页面级文件，以页面级规则覆盖本文件；否则严格遵循本文件。

## 1. 项目定位

- 产品：仅在本机运行的 A 股量化分析工作台。
- 主要设备：桌面浏览器。
- 技术栈：React（前端框架）与 Vite（前端构建工具）。
- 风格：Swiss Modernism 2.0（瑞士现代主义 2.0）。
- 设计参数：变化度 4/10、动效 2/10、信息密度 7/10。
- 核心原则：理性、清晰、严格网格、高对比、最少装饰。

本设计系统只改变视觉和交互表达，不得改变数据、策略、接口、路由、任务回退或历史保存规则。

## 2. 视觉语言

- 使用 12 栏严格网格。
- 使用 8 像素基础间距，常用层级为 8、16、24、32、48、64 像素。
- 允许非对称布局，但所有边界必须与网格对齐。
- 以字号、字重、留白和边框建立层级，不依赖装饰色。
- 常规模块使用直角；表单控件最多使用 2 像素小圆角。
- 常规模块不使用阴影；仅设置抽屉、搜索结果和浮层允许克制阴影。
- 禁止装饰渐变、玻璃拟态、霓虹发光、软圆角卡片堆叠和无意义动效。

## 3. 色彩令牌

| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#0B6B5C` | 当前导航、主要按钮、焦点与关键标识 |
| 品牌深色 | `#084F45` | 品牌色悬停与按压状态 |
| 页面背景 | `#F2EEE6` | 暖米黄纸张底色 |
| 模块表面 | `#FAF8F3` | 主要内容面板 |
| 抬升表面 | `#FFFDF8` | 表格、图表和内部模块 |
| 弱表面 | `#E7E0D4` | 表头、工具条和分段控件 |
| 主文字 | `#171914` | 标题、正文和关键数字 |
| 次级文字 | `#5F5A52` | 描述、标签和辅助信息 |
| 弱文字 | `#7E766B` | 非关键元数据 |
| 常规边框 | `#BDB3A4` | 模块与表格分隔 |
| 强边框 | `#8F8578` | 导航、表单和关键分区 |
| 错误 | `#A93643` | 失败状态与错误操作 |

青绿色是唯一非语义强调色。A 股红涨绿跌属于行情语义色，不得被品牌色替代，也不得只靠颜色传递状态。

已验证的文字对比度：

- 主文字与模块表面：`16.69:1`
- 次级文字与模块表面：`6.44:1`
- 品牌色与模块表面：`6.05:1`
- 白色文字与品牌色：`6.42:1`

以上均满足 WCAG AA（网页内容无障碍指南 AA 级）的正常文字要求。

## 4. 字体与数字

- 标题与正文：Manrope Variable（Manrope 可变字体）。
- 数字、日期、编号和表格：JetBrains Mono Variable（JetBrains Mono 可变等宽字体）。
- 简体中文回退到苹方、微软雅黑等本机系统字体。
- 字体全部随前端本地打包，运行时不得请求外部字体服务。
- 标题字重使用 700—760；正文使用 400—500；标签使用 650—700。
- 数据列使用等宽数字，避免数值变化引起布局跳动。

## 5. 导航与页面框架

- 左侧导航固定显示，采用 `01—05` 编号系统。
- 1440 像素及以上显示完整导航；较窄桌面窗口显示 72 像素紧凑导航。
- 当前页面使用完整品牌色底和白色文字，不能只靠细微颜色差异标识。
- 页面顶栏显示编号、位置、标题、说明、目标日期和设置入口。
- 主要内容与顶栏使用同一水平网格。
- 设置采用右侧抽屉，不作为主导航页面。

## 6. 模块与数据表

- 外层模块使用 1 像素边框、直角、米白背景和 24 像素内边距。
- 指标卡保持同高，标签置顶、关键数字居中、说明置底。
- 表头使用弱表面色，数据行使用细分隔线。
- 表格行悬停只改变背景色，不移动布局。
- 排行榜、技术评分和持仓表保留模块内部横向滚动，不允许整页横向溢出。
- 关键数字、收益率、日期和代码使用等宽字体。

## 7. 图表与行情

- K 线、成交量、RSI（相对强弱指标）和策略曲线优先保证数据可读性。
- 图表背景使用抬升表面色，网格线保持低对比。
- 红绿只表示 A 股上涨与下跌；基准线使用克制蓝色，辅助线使用琥珀色。
- 图例、单位、时间范围和数值标签必须清晰可见。
- 图表加载失败时显示文字原因与恢复路径，不呈现空白坐标轴。

## 8. 控件与交互

- 主要按钮使用品牌主色与白色文字；次要按钮使用边框样式。
- 所有可点击元素必须显示指针光标。
- 桌面主要控件高度至少 40 像素，侧栏与关键按钮至少 44 像素。
- 悬停、焦点、按压和禁用状态必须可区分。
- 键盘焦点使用 2 像素品牌色轮廓。
- 异步按钮在运行期间必须禁用并显示明确文字状态。
- 错误信息必须说明原因和恢复动作。

## 9. 动效

- 微交互时长为 150—300 毫秒。
- 只动画透明度和位移，不动画宽高或位置属性。
- 页面进入动效不超过 220 毫秒。
- 动效必须表达状态变化，不得仅作装饰。
- 必须遵循 `prefers-reduced-motion`（减少动态效果偏好）。

## 10. 桌面断点

- 1280 像素：紧凑侧栏，内容完整，无整页横向溢出。
- 1440 像素：完整侧栏，12 栏网格完整展开。
- 2560 像素：内容限制最大宽度，避免数据区域过度拉伸。
- 项目明确只优化桌面浏览器，不引入手机端底部导航或触摸手势体系。

- [ ] 1280 与 1440 像素无整页横向溢出。
- [ ] 主文字对比度不低于 `4.5:1`。
- [ ] 当前导航、焦点、悬停、禁用、成功和失败状态均可辨识。
