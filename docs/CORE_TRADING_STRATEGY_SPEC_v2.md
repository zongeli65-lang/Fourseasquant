# 核心交易策略规格 v2 差异说明

> 规则版本：`core-strategy-v2`
>
> 基线：除本文明确替换的规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md`。

## 1. 修改原因

v1 在支撑、压力完成失效过滤和结构合并后，按形成时间排序并只保留
两个位置。当多个结构在同一交易日发生极性转换时，远离当前价的动态
趋势线可能排在近端压力之前，导致止盈目标和净盈亏比被高估。

## 2. 替换 v1 第 10 节的选位规则

- 支撑、压力候选仍使用 v1 的识别、失效、极性转换和
  `0.25 × MR20` 合并公式；这些数学公式和阈值不变。
- 合并后的全部有效位置都保留在策略结果中，供页面展示和审计，不再
  截断为两个。
- 当前价下方距离最近的有效支撑决定止损；当前价上方距离最近的有效
  压力决定止盈目标和净盈亏比。
- 只有价格距离相同时，才以形成时间由近到远作为次级排序。
- 当日有效放量突破会检查全部有效压力，选择已经被价格突破的最近一层
  压力完成极性转换；未突破的上方压力继续保留。

## 3. 版本和历史

- v1 已发布结果保持不可变，不原地覆盖。
- 使用新规则重算或继续自动运行时必须发布为 `core-strategy-v2`。
- 页面默认读取同一交易日最后发布的完整版本，因此 v2 完成后会替代
  v1 成为默认展示；v1 仍保存在本机数据库中供追溯。
