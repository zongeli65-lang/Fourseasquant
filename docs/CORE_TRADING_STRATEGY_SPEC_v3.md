# 核心交易策略规格 v3 差异说明

> 规则版本：`core-strategy-v3`
>
> 基线：除本文明确替换的规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md` 与
> `CORE_TRADING_STRATEGY_SPEC_v2.md`。

## 1. 修改原因

v2 已将止盈目标改为按价格距离选择，但仍存在三个边界：

- 压力转支撑后没有重新排序，可能把较远支撑用于止损；
- 当前价位于支撑区域内时，区域距离没有按零处理；
- 当前价已经进入最近压力区域、但尚未有效突破时，可能跳过该区域并
  使用更远目标。

这些边界都会间接改变净盈亏比、机会等级和模拟仓位。

## 2. 替换 v2 的距离与突破规则

- 支撑区域包含当前价时，该区域与当前价的距离为零。
- 当前价进入或无量试穿最近压力区域、但尚未形成有效放量突破时，不得
  跳过该区域改用更远目标；此时压力目标为空，不获得净盈亏比加级。
- 当日有效放量突破检查全部有效压力。所有已被同一收盘价有效突破的
  压力都转为支撑，转换后与原有支撑一起重新按价格距离排序。
- 未被有效突破的压力继续保留；全部上方压力清除后才进入无压力目标
  与利润保护路径。
- 技术证据输出版本提升为 `core-technical-v2`。

## 3. 版本和历史

- v1 与 v2 已发布结果均保持不可变，不原地覆盖。
- 使用本规则重算或继续自动运行时必须发布为 `core-strategy-v3`。
- v3 完整发布后成为页面默认结果；若 v3 未形成完整组合，页面继续展示
  最近一次完整的旧版本组合。
