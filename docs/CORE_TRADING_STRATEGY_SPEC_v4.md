# 核心交易策略规格 v4 差异说明

> 规则版本：`core-strategy-v4`
>
> 基线：除本文明确替换的规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md`、
> `CORE_TRADING_STRATEGY_SPEC_v2.md` 与
> `CORE_TRADING_STRATEGY_SPEC_v3.md`。

## 1. 修改原因

v3 的机会等级直接映射持仓槽位比例。初始资金不足 5 万元时账户只有
一个持仓槽位，因此震荡或下行市场中的 S 级候选也可能产生单股全仓
订单。机会质量等级不应绕过市场状态对应的账户风险约束。

## 2. 市场状态仓位系数

保留 C、B、A、S 的原始仓位比例、支撑来源加成、评级、费用、止损和
压力目标公式，在最终有效仓位中增加市场状态系数：

| 市场状态 | 仓位系数 |
|---|---:|
| 上行 | `1.0` |
| 震荡 | `0.5` |
| 下行 | `0.2` |

有效仓位比例按以下顺序计算：

```text
原始等级仓位
  + 已有支撑来源加成
  → 上限 1.0
  × 市场状态仓位系数
  = 最终有效仓位比例
```

预计净盈亏比和模拟买单必须使用同一个最终有效仓位及其对应整手股数，
避免最低佣金导致评级计算仓位与订单仓位不一致。

`EntryCandidate.net_reward_risk_ratio` 非空时视为上游已经按最终有效整手
股数和同一费用表计算完成的受信快照；正式编排固定传空，由执行层按照
当日实际可用现金自行计算，不使用外部旁路值。

舆论调查前十使用与最终买单相同的现金路径：先预演同日已有持仓退出，
再按每一笔拟买单的整手、费用和剩余现金逐轮重算后续候选。这样实际
最多五个持仓槽位内可能成交的候选不会因为首次静态排序落在调查范围外。

## 3. 版本隔离

- v1、v2 和 v3 重演继续使用仓位系数 `1.0`。
- v4 及后续正式版本才使用市场状态仓位系数。
- v4 发布不得覆盖任何旧版本策略日或组合快照。
- 旧版本 JSON（结构化数据）没有 `market_position_factor` 字段时，
  读取默认值为 `1.0`。

## 4. 当前边界

本规则约束新开仓订单，不新增市场状态变化触发的强制部分卖出。
若持仓在上行期建立后市场转为震荡或下行，仍由既有止损、压力目标和
利润保护规则管理。是否主动减仓属于新的卖出与再平衡规则，必须另行
确认、版本化和回测，不能隐含在本次仓位系数中。
