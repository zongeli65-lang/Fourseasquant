# 核心交易策略规格 v5 差异说明

> 规则版本：`core-strategy-v5`
>
> 基线：除本文明确替换的规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md`、
> `CORE_TRADING_STRATEGY_SPEC_v2.md`、
> `CORE_TRADING_STRATEGY_SPEC_v3.md` 与
> `CORE_TRADING_STRATEGY_SPEC_v4.md`。

## 1. 修改原因

v4 把收盘封涨停视为同等级候选的最高价格优先级，但不阻止模拟买入。
这会在仅有日频行情、无法确认尾盘排队成交的情况下，生成现实中难以
成交的涨停收板买单。

## 2. 收盘封涨停禁止新买入

- 使用不复权行情和主板涨停价计算规则判断当日是否收盘封涨停；
- 只要收盘价达到当日涨停价，当日一律禁止新买入；
- 即使候选拥有有效分歧买入触发、S 级机会、充足现金或其他强证据，
  也不得生成模拟买单；
- 收盘封涨停的候选不占用当日舆论调查前十名额；
- 涨停事实本身仍不改变 S/A/B/C 机会等级；
- 本次未成交的买入信号不顺延为次日订单，下一交易日必须重新计算
  全部条件；
- 本规则只限制新买入，不改变已有持仓的卖出、止损、止盈和利润保护。

## 3. 版本隔离

- v1 至 v4 的历史结果与重演语义保持不变；
- v5 及后续版本才应用收盘封涨停禁止新买入规则；
- v5 发布不得覆盖任何旧版本策略日、调查准备或组合快照。
