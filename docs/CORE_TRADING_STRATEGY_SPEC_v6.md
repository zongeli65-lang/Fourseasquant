# 核心交易策略规格 v6 差异说明

> 规则版本：`core-strategy-v6`
>
> 技术证据版本：`core-technical-v3`
>
> 基线：除本文明确替换的压力确认规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md` 至
> `CORE_TRADING_STRATEGY_SPEC_v5.md`。

## 1. 修改原因

此前压力转支撑只接受放量确认。收盘价已经明显越过压力区域、但成交量
未达到放量门槛时，旧压力仍会阻塞更高压力目标，并使部分候选缺少可用
的盈亏比。

## 2. 压力区域三态

- 收盘价尚未超过压力区域上沿时，该区域仍是有效压力。
- 收盘价超过上沿、但超出距离不足压力区域宽度的 `0.5` 倍时，该区域
  进入悬置状态：保留该压力记录，但当前目标改为更高的有效压力。
- 收盘价达到或超过“上沿加压力区域宽度的 `0.5` 倍”时，即使没有放量，
  也确认突破；该压力转为支撑，并继续寻找更高压力。
- 原有放量突破条件保持不变，仍可独立确认压力突破。
- 单点压力的上下沿相同、没有区域宽度，因此本次不应用价格倍数确认，
  仍沿用原有放量确认路径。
- 日频策略只使用收盘价确认，盘中短暂越界不触发转换。

## 3. 版本隔离

- v1 至 v5 的历史结果和重演语义保持不变。
- v6 及后续版本使用本规则。
- v6 发布不得覆盖旧版本策略日、调查准备或组合快照。
