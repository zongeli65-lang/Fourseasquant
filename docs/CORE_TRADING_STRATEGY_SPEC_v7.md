# 核心交易策略规格 v7 差异说明

> 规则版本：`core-strategy-v7`
>
> 技术证据版本：`core-technical-v4`
>
> 基线：除本文明确替换的压力目标选择规则外，继续遵循
> `CORE_TRADING_STRATEGY_SPEC_v1.md` 至
> `CORE_TRADING_STRATEGY_SPEC_v6.md`。

## 1. 压力目标选择

- 收盘价进入一个压力区域后，该区域仍保留为有效压力记录，但不再作为
  当前止盈目标。
- 系统必须继续向上寻找下一个下沿高于当前收盘价的压力区域，并把其
  下沿作为新的压力目标。
- 进入压力区域本身不改变原有支撑，也不构成压力转支撑。
- v6 的悬置和确认规则保持不变：超过上沿但不足区域宽度的 `0.5` 倍时
  保留悬置；达到上沿加区域宽度的 `0.5` 倍时确认突破并转为支撑。
- 只有完整历史上确实不存在更高压力时，才允许进入“新高”状态；数据
  覆盖不足时不得以“新高”替代缺失压力。

## 2. 版本隔离

- v1 至 v6 的历史结果和重演语义保持不变。
- v7 及后续版本使用本规则。
- v7 发布不得覆盖任何旧版本策略日或组合快照。
