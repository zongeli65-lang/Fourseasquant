# 核心交易策略规格 v8 差异说明

> 规则版本：`core-strategy-v8`
>
> 基线：完整继承 `CORE_TRADING_STRATEGY_SPEC_v1.md` 至
> `CORE_TRADING_STRATEGY_SPEC_v7.md` 的全部公式、参数、权重、评分、
> 仓位、止盈、止损、卖出和持仓管理规则。

## 1. 编排错误修复

- 市场状态为上行时，按既有规则运行技术主线、产业链、基本面和舆论
  调查流程。
- 市场状态为震荡或下行时，只运行纯技术选股和既有持仓管理，不发布
  基本面或舆论调查目标，也不等待调查超时。
- 无论市场状态如何，已有持仓都必须使用当日收盘价完成估值，并执行
  既有止损、止盈、压力目标和利润保护规则。

## 2. 数学规则保持不变

本版本不修改任何技术指标公式、候选排行、机会等级、仓位比例、市场
系数、交易费用、支撑压力、止盈止损或收益计算公式。版本号提升仅用于
隔离已发布的 v7 错误调查准备快照，禁止覆盖或删除旧记录。
