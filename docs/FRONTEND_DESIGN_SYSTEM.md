# Fourseasquant 前端设计系统

## 1. 设计目标

Fourseasquant 是仅在本机使用的 A 股量化工作台。前端采用现代、品牌化的深色数据产品风格，同时把数据可读性、操作稳定性和长期扩展放在装饰效果之前。

本设计系统只约束视觉、布局和交互表达，不得改变后端接口、策略逻辑、技术评分、行情语义或数据完整性规则。

## 2. 品牌语言

- 品牌名称：`Fourseasquant`
- 核心意象：四条流动曲线汇聚，表达四海、数据流与趋势。
- 主背景：深海蓝黑，不使用纯黑。
- 品牌强调色：冷青色 `#4fd1c5`。
- 涨跌颜色：A 股红涨绿跌，仅用于行情与收益语义。
- 禁止把品牌冷青色当作上涨或下跌信号。
- 禁止廉价霓虹、持续发光、大面积玻璃拟态和通用蓝紫渐变。

品牌图标位于：

```text
frontend/public/fourseas-mark.svg
```

浏览器图标和应用内图形必须保持同一意象。

## 3. 字体与数字

- 界面字体：Manrope Variable（Manrope 可变字体）。
- 数字与数据表：JetBrains Mono Variable（JetBrains Mono 可变等宽字体）。
- 简体中文回退到 macOS 本机的苹方等系统字体。
- 字体文件由前端构建打包，运行时不得依赖外部字体服务或 CDN（内容分发网络）。
- 数据列使用等宽数字，保证小数点和位数易于纵向比较。

## 4. 页面结构

| 路径 | 页面 | 主要内容 |
|---|---|---|
| `/overview` | 总览 | 数据日期、服务与任务状态、策略摘要、技术评分前五、每日笔记 |
| `/market` | 市场 | 指数、市场广度、排行榜、成交额与热力图 |
| `/quotes` | 行情 | 股票和指数搜索、日 K、成交量、RSI（相对强弱指标） |
| `/strategy` | 策略 | 完整技术评分、策略净值、组合、交易与收益贡献 |
| `/tasks` | 任务 | 每日任务、失败回退、任务历史、重新运行 |

根路径 `/` 默认进入 `/overview`。所有页面保留目标日期；行情页同时保留股票或指数选择。生产式本机服务必须支持直接刷新上述路径。

## 5. 导航与布局

- 使用固定左侧导航栏，支持手动折叠。
- 在较窄桌面窗口自动显示紧凑侧栏。
- 页面顶部固定显示当前位置、页面标题、目标日期和设置入口。
- 主要适配 1440—2560 像素桌面浏览器，1280 像素保持完整可用。
- 内容采用中等偏宽松密度，不回到传统行情软件的极端紧凑布局。
- 表格、图表或热力图超出可用宽度时，只允许模块内部滚动，不允许整页产生无意义横向滚动。

## 6. 表面与层级

- 页面背景使用深海蓝黑和克制的环境光。
- 只有能表达信息层级的模块才使用卡片表面。
- 外层容器圆角大于内部控件圆角。
- 边框使用低对比冷灰蓝，品牌边框只用于当前导航或重点操作。
- 阴影带背景色相，不使用通用纯黑重阴影。
- 数据面板之间保留稳定的 18—24 像素视觉间隔。

## 7. 交互与动效

- 页面切换、侧栏折叠、按钮悬停和按压使用 180—260 毫秒的轻量过渡。
- 不引入 GSAP（专业网页动画库）或滚动固定、卡片堆叠等营销页动效。
- K 线、排行榜、表格和任务状态不得因装饰动画产生位置漂移。
- 必须支持键盘焦点样式和系统“减少动态效果”设置。
- 点击市场排行、热力图、技术评分、持仓或交易中的股票，应进入 `/quotes` 并保留代码、名称和目标日期。

## 8. 状态表达

- 加载、空数据、失败和成功状态必须有明确文字，不得只依赖颜色。
- 每日任务失败时，所有页面顶部继续展示醒目失败横幅。
- 失败横幅必须保留失败阶段、时间、摘要与重新运行入口。
- 残缺结果不得覆盖最近一次完整成功结果。
- 无真实数据时不得使用模拟板块排行或伪造市场结论填充界面。

## 9. 离线与隐私

- 页面运行时不得请求外部字体、图片、图标或分析脚本。
- 品牌资源和字体随项目本地构建。
- 网站仅绑定本机回环地址，不增加公网发布依赖。
- 设置、日志和页面不得暴露密码、令牌或其他秘密。

## 10. 后续修改验收

任何前端视觉修改至少运行：

```zsh
npm run typecheck
npm test
```

还应使用真实本机数据检查：

- 五个独立路径可直接打开和刷新；
- 左侧导航的当前页状态正确；
- 目标日期和所选股票跨页面保留；
- 1440 像素及以上桌面无整页横向滚动；
- A 股红涨绿跌没有被品牌色覆盖；
- 设置面板、失败横幅和键盘焦点位于正确层级；
- 浏览器控制台没有新增错误。
