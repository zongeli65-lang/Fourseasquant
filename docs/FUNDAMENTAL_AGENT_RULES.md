# 基本面 Agent（智能体）边界

当前版本不调用 Agent。基本面正式结果全部来自 `personal-fundamental-v1` 机械规则。

未来即使接入 Agent，也只能：

- 帮助定位公开报告中的表格和页码；
- 将无法稳定读取的分部数据转成待人工确认的结构化草稿；
- 指出来源冲突，不得自行裁决或填补数据；
- 引用原网址，不保存大段受版权保护的正文。

Agent 永远不得：

- 修改机械公式、分值或原始数值；
- 生成买卖、目标价和仓位建议；
- 用定性叙事提高任何分数；
- 把公告计划写成已经完成；
- 在没有新来源时重复分析；
- 绕过登录、验证码或反爬限制。

任何未来 Agent 入口必须独立、默认关闭，并且不能被月度或每日机械任务自动调用。
