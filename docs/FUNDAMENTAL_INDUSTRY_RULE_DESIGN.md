# 个人基本面行业个性化规则设计
## 1. 文档状态

- 设计版本：`personal-fundamental-industry-v1`
- 板块输入版本：数据库中 `2026-07-24` 的完整 `sina` 板块候选快照
- 当前输入规模：84 个行业板块、175 个概念板块
- 适用规则：`personal-fundamental-v1`
- 目标：在不调用 Agent（智能体）、不生成百分制总分的前提下，让每个现有行业板块使用适合自身财务结构的彼得·林奇指标组合。
- 非目标：不引入预测模型、目标价、仓位建议、技术指标或新的专业估值体系。

本文件是工程设计，不表示当前代码已经实现。代码实现前必须把板块映射、规则版本和数据完整性门禁固化为可测试配置。

## 2. 输入边界

### 2.1 行业板块

只有 `kind=industry` 的板块可以决定财务行业模板。映射键使用稳定的 `source + source_board_code`，板块名称只用于展示，不能作为唯一主键。

### 2.2 概念板块

`kind=concept` 的板块只用于：

- 发现候选股票；
- 板块内抽样；
- 展示市场讨论主题。

概念板块不得：

- 改变财务指标适用性；
- 改变林奇机械排序；
- 产生第二套财务行业；
- 用热度覆盖行业财务结果。

### 2.3 一只股票的行业归属

正常情况下，一只股票必须匹配一个财务行业模板。

- 只属于一个行业板块：直接使用该板块映射。
- 同时属于多个行业板块：标记 `ambiguous_industry`（行业冲突），禁止发布最终机械等级，等待来源修正。
- 不属于任何行业板块：使用 `unmapped_industry`（行业未映射），只展示原始四支柱数据，禁止发布最终机械等级。
- 板块快照不完整：沿用最近一个完整快照；没有完整快照时停止行业化计算。

不得根据公司名称、股票代码或概念板块猜测行业。

## 3. 非百分制结果契约

### 3.1 单项适用性

每项林奇指标先得到一个行业角色：

| 角色 | 含义 |
|---|---|
| `core` | 该行业的核心机械判定项 |
| `supporting` | 辅助排序项，不能单独决定结果 |
| `display_only` | 只展示事实，不参与机械排序 |
| `not_applicable` | 对该行业没有可靠经济含义 |
| `insufficient_data` | 原本适用，但数据不足 |

`not_applicable` 和 `insufficient_data` 都不得转换为零分。

### 3.2 单项机械状态

对 `core` 和 `supporting` 指标，沿用现有林奇规则和事实阈值，输出：

- `favorable`（较好）
- `neutral`（中性或没有明确评价）
- `unfavorable`（较差）
- `not_applicable`（不适用）
- `insufficient_data`（数据不足）

不得为了凑齐百分制自行扩大彼得·林奇原文阈值。林奇增长估值比仍只使用现有约束：小于 1 较差、约 1.5 尚可、大于等于 2 较好，1 至 1.5 之间不另造标签。

### 3.3 发布门禁

以下任一条件成立时，不发布最终机械层级：

- 行业未映射或行业冲突；
- 模板规定的估值主指标缺失；
- 核心指标中超过一半为 `insufficient_data`；
- 主营业务无法由分部利润或毛利润确定；
- 财务证据未通过现有来源和内容哈希校验。

门禁失败时仍可展示已取得的事实，但状态必须为 `incomplete`，不能按已有指标重新分配权重。

### 3.4 机械排序

不计算四支柱总分。候选股票按以下排序元组依次比较：

```text
发布状态
→ 行业模板置信状态
→ 行业估值主序
→ 核心不利项数量（少者优先）
→ 核心有利项数量（多者优先）
→ 主营业务是否明确
→ 流通市值区间
→ 真金白银信号分
→ 当日讨论热度
→ 股票代码（保证结果稳定）
```

约束：

- 后序项目不得抵消前序项目。例如，高热度不能抵消核心财务不利项。
- 流通市值和热度仍可使用百分位，但不与财务指标相加。
- 舆情方向单独展示为每日覆盖层，不进入月度财务排序。
- 同行业内排序；不同财务行业模板的股票不直接比较“谁的基本面分更高”。

## 4. 财务行业模板

以下模板只重新安排既有彼得·林奇指标的角色，不引入新指标。

### T01 通用制造

- 估值主序：林奇增长估值比，其次扣非市盈率的同行与自身历史位置。
- 核心：扣非盈利增长、扣非市盈率、净现金与有息债务、自由现金流代理值、存货增长差、税前利润率。
- 辅助：股息、连续分红、真金白银信号。
- 适用场景：设备、材料加工、耐用品及大部分工业制造。

### T02 消费与医药制造

- 估值主序：林奇增长估值比，其次扣非市盈率同行位置。
- 核心：长期扣非盈利增长、扣非市盈率、税前利润率、自由现金流代理值、存货增长差。
- 辅助：净现金、股息、连续分红、真金白银信号。
- 特别约束：存货适用，但必须结合收入增长，不把存货绝对增加直接判坏。

### T03 周期资源与上游材料

- 估值主序：扣非市盈率的公司历史与同行位置；林奇增长估值比降为辅助。
- 核心：净现金与有息债务、自由现金流代理值、税前利润率、股息。
- 辅助：五年正增长年度数、存货增长差、林奇增长估值比、真金白银信号。
- 特别约束：单年高利润和高增长不得覆盖历史位置与现金负债状态。

### T04 公用事业与重资产运营

- 估值主序：扣非市盈率同行与自身历史位置，其次股息率。
- 核心：股息与连续分红、有息债务、自由现金流代理值、税前利润率。
- 辅助：扣非盈利增长、净现金、林奇增长估值比、真金白银信号。
- 不适用：存货，除非板块例外明确启用。

### T05 交通运输与物流

- 估值主序：扣非市盈率历史与同行位置；盈利稳定时才使用林奇增长估值比。
- 核心：有息债务、自由现金流代理值、税前利润率、股息。
- 辅助：扣非盈利增长、净现金、真金白银信号。
- 不适用：存货。

### T06 银行

- 估值主序：扣非市盈率的银行同行与公司历史位置。
- 核心：扣非盈利增长、扣非市盈率、股息、连续分红、真金白银信号。
- 辅助：五年正增长年度数、林奇增长估值比。
- 不适用：普通净现金、有息债务比、自由现金流代理值、存货增长差。
- 特别约束：低市盈率只能改善估值主序，不能自动形成最高机械层级。

### T07 非银行金融

- 估值主序：扣非市盈率的细分同行与公司历史位置。
- 核心：扣非市盈率、五年正增长年度数、股息、真金白银信号。
- 辅助：扣非盈利增长、林奇增长估值比、连续分红。
- 不适用：普通净现金、有息债务比、自由现金流代理值、存货增长差。
- 特别约束：保险、资本市场服务和其他金融分别计算同行位置，不混为一个同业样本。

### T08 房地产与建筑

- 估值主序：扣非市盈率的同行与自身历史位置；林奇增长估值比降为辅助。
- 核心：净现金与有息债务、自由现金流代理值、存货增长差、税前利润率。
- 辅助：扣非盈利增长、扣非市盈率、股息、真金白银信号。
- 特别约束：低市盈率不得覆盖现金、债务或存货核心不利项。

### T09 轻资产科技与专业服务

- 估值主序：林奇增长估值比，其次扣非市盈率同行位置。
- 核心：长期扣非盈利增长、扣非市盈率、净现金、自由现金流代理值、税前利润率。
- 辅助：五年正增长年度数、真金白银信号、股息。
- 不适用：存货，板块例外明确启用时除外。

### T10 农林牧渔

- 估值主序：扣非市盈率历史与同行位置；盈利连续为正时才使用林奇增长估值比。
- 核心：净现金与有息债务、自由现金流代理值、存货增长差、税前利润率。
- 辅助：五年正增长年度数、股息、真金白银信号。
- 特别约束：周期波动不能由单年增长率覆盖。

### T11 商贸、生活服务与传媒

- 估值主序：林奇增长估值比；盈利波动时退回扣非市盈率历史与同行位置。
- 核心：扣非盈利增长、扣非市盈率、自由现金流代理值、税前利润率。
- 辅助：净现金、股息、真金白银信号。
- 存货：批发、零售、餐饮和住宿为核心或辅助；纯服务、教育和传媒通常不适用。

### T12 特殊或样本不足

- 不发布行业化机械层级。
- 展示已有林奇事实、主营业务、流通市值、真金白银信号和舆情。
- 适用场景：综合行业、成员为空或行业含义不足以稳定映射的板块。

## 6. 小样本和同行比较

第一版使用以下发布原则，不对小样本百分位制造精确感：

- 同行业有效样本不少于 20：可以发布同行百分位。
- 有效样本 5 至 19：只发布原始排序位置和样本数，不发布百分位标签。
- 有效样本少于 5：同行比较为 `insufficient_peer_sample`（同行样本不足）。

这里的有效样本是同一报告期、同一指标有值且通过证据校验的股票数量，不是板块名义成员数。

## 7. 配置与可追溯性

工程实现应把以下内容保存为版本化配置，而不是散落在条件语句中：

```text
source
source_board_code
industry_profile_id
profile_version
indicator_roles
valuation_order
board_overrides
effective_from
```

每份月度结果同时保存：

- 原始行业板块代码和名称；
- 使用的财务行业模板；
- 模板版本；
- 各指标的行业角色与机械状态；
- 发布门禁结果和原因；
- 排序元组的各个原始分量；
- 来源网址和内容哈希。

板块来源更新但映射未更新时，新增行业必须进入 `unmapped_industry`，不能自动套用名称相似的模板。
