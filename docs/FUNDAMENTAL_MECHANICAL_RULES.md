# 个人基本面机械规则

## 1. 目标与边界

- 规则版本：`personal-fundamental-v1`
- 适用市场：A 股
- 目标：用个人开发者可以长期维护的四个支柱筛选和查看股票。
- 处理方式：全部由确定性代码计算，不调用 Agent（智能体）。
- 非目标：不生成专业研报、目标价、买卖建议、仓位建议或综合基本面总分。

板块、热门榜和讨论热度只负责发现候选。没有财报或来源更新时，不重新解析同一份证据。

## 2. 更新频率

| 内容 | 频率 | 更新规则 |
|---|---|---|
| 林奇核心数据 | 每月最后一个交易日 | 财报不变时复用旧解析，只重算月末估值和滚动公司行动 |
| 主营业务 | 每月检查 | 只有新年报、半年报或分部披露时改变 |
| 流通市值 | 每月最后一个交易日 | 使用月末收盘价 |
| 热度与舆情 | 每日 | 分平台计算后合并 |

## 3. 第一支柱：彼得·林奇核心数据

### 3.1 收益、增长与市盈率

```text
普通滚动十二个月市盈率 = 总市值 / 滚动十二个月归母净利润
扣非滚动十二个月市盈率 = 总市值 / 滚动十二个月扣非归母净利润
```

扣非利润或归母净利润不大于零时，对应市盈率为“不适用”，不得输出负市盈率。

长期增长使用最近五个完整年度的扣非每股收益。五个年度点通常形成四个年度间隔，代码按首尾年度之差计算指数，不把它误写成固定五年间隔：

```text
五年扣非每股收益复合增长率
= (期末扣非每股收益 / 期初扣非每股收益)^(1 / 年数) - 1
```

期初或期末扣非每股收益不大于零时不计算。另保留五年中同比增长为正的年度数量。

林奇增长估值比：

```text
(五年盈利增长率百分数 + 股息率百分数) / 扣非滚动十二个月市盈率
```

严格沿用书中提示：

- 小于 1：较差；
- 约 1.5：尚可；
- 大于等于 2：较好；
- 1 至 1.5 之间不自行创造评价标签。

当前扣非市盈率同时展示其在公司历史值和同行值中的百分位，不形成新评分。

### 3.2 现金和负债

```text
净现金
= 现金及现金等价物
- 短期有息债务
- 长期有息债务

每股净现金 = 净现金 / 总股本
现金调整股价 = 股价 - 每股净现金
现金调整市盈率 = (总市值 - 净现金) / 滚动十二个月扣非归母净利润
负债权益比 = 全部有息债务 / 归母净资产
短期债务占比 = 短期有息债务 / 全部有息债务
```

分母不大于零时，对应比例为“不适用”。

### 3.3 股息

```text
股息率 = 滚动十二个月现金股利 / 总市值
股利支付率 = 滚动十二个月现金股利 / 滚动十二个月归母净利润
```

另保留连续现金分红年数。亏损时不计算股利支付率。

### 3.4 自由现金流

```text
自由现金流代理值
= 经营活动现金流净额
- 购建固定资产、无形资产和其他长期资产支付的现金

每股自由现金流 = 自由现金流 / 总股本
股价自由现金流比 = 总市值 / 自由现金流
```

财报无法机械区分维持性和扩张性资本支出，因此必须明确标记为代理值。自由现金流不大于零时不计算股价自由现金流比。

### 3.5 存货与税前利润率

```text
存货增长差 = 存货增长率 - 营业收入增长率
税前利润率 = 利润总额 / 营业收入
```

存货增长快于收入时如实展示正差值。税前利润率只与自身历史和同一行业比较。输入必须明确存货规则是否适用。银行等存货无实际意义的行业输出 `not_applicable`（不适用）；适用但字段不足时输出 `insufficient_data`（数据不足），不创造替代指标。

### 3.6 股东与公司资本行为

核心事实包括：

- 内部人士主动现金增持和减持；
- 已完成并注销的回购；
- 增发、配股和转股造成的实际股本稀释。

回购计划、尚未注销的回购以及用于员工持股或股权激励的回购不加分。公募基金重仓和机构持股比例不采集、不展示，也不参与评分；“公司是否被机构忽视”属于无法由单一持仓比例可靠机械化的定性观察。

注销式回购金额与股数必须来自能够一对一对应本轮回购的官方注销完成公告。
第三方回购汇总可用于发现候选证据，但不能单独激活评分。

```text
真金白银信号分
= 50
+ 内部人士交易调整分
+ 注销式回购奖励分
- 股本稀释扣分
```

| 项目 | 影响范围 | 第一版满额尺度 |
|---|---:|---:|
| 内部人士交易 | -30 至 +30 | 近十二个月净交易额达到平均流通市值的正负 0.3% |
| 已注销回购 | 0 至 +20 | 近十二个月注销回购额达到平均流通市值的 1% |
| 股本稀释 | 0 至 -20 | 近十二个月新增股本达到发行前股本的 10% |

区间内线性计算，最终限制在 0 至 100 分。三项都未发生时为中性 50 分。结果同时保留内部人士净交易额、注销回购金额、新增股数、发行前股数、各自比例和分项加减分。这是用户个人规则，不冒充彼得·林奇原始公式。

若高管交易来源不能证明目标日前完整十二个月窗口，内部人士金额、比例和
调整分均为空值并显示“无法确定”，该分项按中性零调整处理；不得把未知写成
真实的零交易。

## 4. 第二支柱：主营业务

优先使用公司披露的分部利润；只有各业务都没有分部利润时才退回毛利润。没有分部利润时：

```text
业务毛利润 = 该业务营业收入 - 该业务营业成本
主营业务 = 毛利润金额最高的业务
主营业务利润占比 = 主营业务毛利润 / 全部已披露业务毛利润
```

同一份披露中只有部分业务提供分部利润时标记为“无法确定”，不得把分部利润与毛利润混算。只有收入、没有成本或分部利润时也标记为“无法确定”，不得用收入占比冒充利润占比。

## 5. 第三支柱：流通市值

```text
流通市值 = 实际流通股本 × 月末收盘价
流通市值得分 = 流通市值在全部正常交易 A 股中的百分位
```

解释：

- 0 至 30 分位：流通市值较小；
- 30 至 70 分位：中等；
- 70 至 90 分位：具备较充分的多方资金博弈空间；
- 90 至 100 分位：流通市值很大。

不加入成交额和换手率。

如果目标日期缺少全部正常交易 A 股的完整流通市值母体，百分位保持空值；
不得用最多 200 只基本面候选池代替全市场母体。

## 6. 第四支柱：热度与舆情

候选热度可来自东方财富、同花顺或新浪的热门股票及板块数据。投资者舆情来自东方财富股吧和雪球公开讨论；输入模型只接受标记为用户原创的内容，公告、研报、公司新闻和媒体转载不能进入舆情。

不进行内容去重。同一用户重复发帖、不同帖子使用相同文字都分别计数。只有爬虫重复读取同一平台帖子编号时才进行技术去重。

固定词典将帖子判为利好、中性或利空。利好与利空同时出现时判为中性。

```text
单帖权重 = 1 + 自然对数(1 + 点赞数)

平台加权舆情
= Σ(情绪值 × 单帖权重) / Σ单帖权重

平台热度原值 = Σ单帖权重
平台热度得分 = 平台热度原值在当日全部 A 股中的百分位
```

情绪值：利好为 `+1`，中性为 `0`，利空为 `-1`。点赞数缺失时单帖权重为 1，并记录缺失。

东方财富股吧与雪球分别计算，综合热度和综合舆情各按 50% 合并。任一平台缺失时综合值也标记缺失，不用另一平台伪造。

## 7. 数据来源与保存

- 财务正式证据：巨潮资讯、交易所和上市公司正式披露。
- 结构化接口：AKShare（A 股数据接口库）可用于取得和交叉核验数值。
- 板块候选：东方财富、同花顺或新浪，仅用于候选发现和同行归类。
- 舆情：只处理无需绕过登录或反爬限制的公开内容。

长期保存：

- 每日和每月汇总；
- 规则版本；
- 来源网址；
- 内容哈希；
- 当月变化字段。

单帖引用只保存平台、帖子编号、网址、时间、点赞数、机械情绪和股票代码，保留三十天；不保存正文。
