# 基本面技能采用审查

第一版只采用能够帮助确定性工程落地的方法：

| 技能 | 采用内容 | 不采用内容 |
|---|---|---|
| `tdd`（测试驱动开发） | 先验证公式、去重边界、保存规则和板块导入 | 不测试私有实现 |
| `code-review`（代码审查） | 分别检查仓库规范和需求符合度 | 不用审查结果扩大需求 |
| 数据质量方法 | 缺失值不得伪装为零；不完整板块快照不得发布 | 专业三表审计体系 |
| 可比公司方法 | 市盈率和税前利润率只与合理同行比较 | 复杂机构级估值模型 |

以下技能不进入第一版流水线：三张报表模型、现金流折现模型、首次覆盖研报、盈利预测、竞争分析和投资假设跟踪。原因是它们会把个人四支柱系统扩展成专业研究系统。
