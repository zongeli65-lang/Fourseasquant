记录时间：2026-07-27
状态：诊断完成；2026-07-28 用户决定不修改主营认定，只实施多正式来源证据拼接。

### 问题

大多数企业不会披露细分产品的营业收入占比或毛利润占比。缺少数字不等于相关产品不是实质主营；如果只允许量化占比或公司直接使用“核心主营”等明确表述，可能误杀能够通过持续调查确认主营地位的企业。

### 候选解决方案

将主营认定拆为三个互相独立的通过通道：

1. `quantitative_confirmed`：公司披露收入或毛利润占比，按量化规则判断；
2. `official_qualitative_confirmed`：正式披露直接确认主营、核心产品、主要利润来源、重大客户或批量商业化；
3. `investigation_confirmed`：没有量化占比或直接定性结论，但 Agent 通过生产基地与产线、持续经营历史、客户与批量供货、订单与销售、资本投入、上市公司归属以及反证搜索形成完整调查证据链。

第三通道不是关键词计数或程序估算占比。Agent 负责判断多项经营事实能否共同确认主营，程序只校验证据来源、时间、主体、产品、引用完整性和已披露反证。有明确低占比、尚未形成收入、仅送样验证、仅远期规划或不归属于上市公司的反证时，不得使用调查确认。

`investigation_confirmed` 主营通道未实施。量化主营、正式定性主营及其现有阈值保持不变。

### 已实施的多来源拼接

- 行业需求证据使用当前 72 小时内、发布时间可核验的一级至三级正式来源；
- 公司兑现证据使用当前时点前 92 天内、主体和产品一致的正式来源；
- 单篇公司材料明确订单、批量供货、销量或收入增长时直接确认兑现；
- 没有单篇直接材料时，可由“当前行业需求 + 公司商业化量产、稳定供应、销售或客户覆盖”拼接确认；
- 更新或同期正式材料明确尚未形成订单、批量供货、销售或收入，或仍处于送样、验证、测试、研发、规划、建设阶段时否决；
- 主营规则没有改变，扩产或投产单独存在时仍不能证明受益。
