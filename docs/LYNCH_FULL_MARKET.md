# 全市场三年林奇比

## 版本与用途

- 规则版本：`lynch-core-v2`
- 用途：为沪深主板、创业板、科创板建立统一的短线基本面硬度切片。
- 边界：不划分彼得·林奇公司类型，不生成基本面总分、目标价或投资建议。
- 核心公共底座只包含盈利增长、估值、财务安全三个独立维度；林奇比是派生结果。

## 股票范围

读取目标交易日的 AKShare 正式日频行情，纳入沪深主板、创业板和科创板，
排除北交所、ST、退市名称、上市不足 60 个交易日以及无有效收盘价的股票。

## 计算规则

使用目标日期前已公告的最近三个连续完整会计年度扣非每股收益，以及当前
TTM（最近十二个月）扣非每股收益。财务安全使用同报告期的
`（有息负债 - 现金）/ 归母净资产`。

`林奇比 =（三年扣非每股收益复合增长率 + 最近十二个月股息率）/ 扣非市盈率`

每只股票在每个完整批次中都保留一行，并具有相同的量化字段和状态：

- `growth_status`：盈利增长状态。
- `valuation_status`：估值是否适用。
- `financial_safety_status`：财务安全数据是否有效。
- `core_data_status`：`complete`（完整）、`economic_not_applicable`
  （经济含义不适用）或 `source_missing`（上游来源缺失）。

亏损、归母净资产非正等经济情况不会被当作缺失，也不会从股票全集删除；
上游缺失不会被填成 0。

绝对等级：

- 大于等于 2：卓越
- 1.5 至 2：优秀
- 1 至 1.5：合理
- 0 至 1：偏弱
- 小于 0：盈利收缩
- 无法计算：数据不足

正式市场百分位只在林奇比可计算的股票中生成。审计意见、业绩预告和重大
公开风险继续作为独立证据与警告保存，但不再冒充林奇核心维度，也不阻断
有效股票的横截面排名。

## 数据发布

- 财务基座：完整批次原子发布，逐股缓存支持断点续跑；包括同报告期资产负债表。
- 日频结果：每个交易日全量重算并永久保存。
- 任何网络或解析失败都会使整批失败，不覆盖上一份完整结果。
- 财务基座 32 至 45 天显示陈旧警告；超过 45 天停止发布新日频结果。

## 调用

首次全量初始化：

```bash
cd /Users/lz666/Documents/quant/fourseasquant-t01
npm run data:lynch-init -- --as-of 2026-07-24 --workers 16
```

只刷新财务基座：

```bash
npm run data:lynch-base -- --as-of 2026-07-24 --workers 16
```

只进行每日本地重算：

```bash
npm run data:lynch-daily -- --target-date 2026-07-24
```

网站接口：

```text
GET /api/fundamentals/lynch/overview?target_date=2026-07-24
```

自动任务在每日行情成功后运行；没有财务基座或基座达到刷新阈值时先执行
AKShare 全量财务采集，再执行本地日频重算。
