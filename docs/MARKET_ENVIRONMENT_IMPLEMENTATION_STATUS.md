# 机械市场环境板块实施状态

版本：`market-environment-v1`
用途：独立判断上证、深证及沪深主板整体环境；不修改个股技术分，不参与产业链龙头选取。

## 正式规则

- 上证指数、深证成指分别计算快速方向。
- 快速方向由“3日标准化收益、5日标准化斜率、10日收盘突破或跌破”三项取二。
- 普通上升和下降需沪深方向一致并连续两个交易日；沪深实质分歧按震荡处理。
- 上升触发后五个交易日内，以10日收益、10日斜率、已确认摆动结构或突破位守住情况进行慢速验证。
- 极端下降在沪深同时快速看跌，且上涨家数、新高新低、涨跌停、放量抛售四项压力中至少两项成立时当日确认。
- 市场广度使用主板上涨家数、新高新低和五日扩散情况；成交容量使用主板成交额相对20日中位数。
- 120日成交成本压力只是成交量加权代理，不是真实持仓成本，不参与状态判定。
- 指数蜡烛图和RSI背离只生成会自动失效的独立提示。
- 个股技术评分表不是本模块输入。

## 生产接口

```http
GET /api/market-environment?target_date=YYYY-MM-DD
GET /api/market-environment/history?end_date=YYYY-MM-DD&limit=60
POST /api/market-environment/refresh
```

核心深模块：

```text
backend/fourseasquant/market_environment.py
```

外部只需要调用生成目标日快照、读取目标日快照、读取历史三个接口。指数技术、主板聚合、状态机、慢速验证、风险提示、不可修改发布均隐藏在模块内部。

## 数据与版本

- 指数来源：`akshare_index_sh000001`、`akshare_index_sz399001`
- 主板来源：`akshare_sina_daily`
- 股票范围：沪深主板、上市至少60个交易日、非ST、当日有成交
- 当前参数：3日收益标准化阈值 `0.50`，5日标准化斜率阈值 `0.08`
- 参数来源：用户确认的快速/慢速架构、技术形态规范首轮斜率值及本机候选参数检查
- 数据库版本：30
- 历史快照和运行审计只追加，不允许更新或删除

截至2026年7月27日，本机已用真实行情发布283个历史快照；最新实际数据日为2026年7月24日。

## 页面

```text
http://127.0.0.1:5173/market-environment
```

页面独立展示：

- 当前上升、下降或震荡状态；
- 上证和深证快速、慢速分项证据；
- 市场广度与成交容量；
- 仅展示的成交成本压力代理；
- 仍有效的指数形态和RSI背离提示；
- 最近一年的逐交易日状态时间轴、上涨/下跌/震荡日数占比和连续状态区间；
- 最近状态切换历史。

## 已知研究限制

当前本机上证、深证与全市场共同历史从2025年4月开始，只有约14个月，尚不足以证明参数跨完整牛熊周期稳定。生产快照因此完整保留规则版本和分项证据；未来扩大历史区间并完成时间滚动、样本外检验时，应发布新规则版本，不回写 `market-environment-v1` 历史。
