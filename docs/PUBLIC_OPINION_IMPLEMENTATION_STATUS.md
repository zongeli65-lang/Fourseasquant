# 舆论监测工程实现状态

更新日期：2026-07-28

## 当前来源职责

| 来源 | 职责 | 自动执行 | 完整性 |
|---|---|---:|---|
| 核心策略 | 每日发布有序的舆论调查股票代码，最多 10 只 | 是 | 只接受完整、带日期和策略版本的不可覆盖快照 |
| 新浪股吧 | 主题、回复、时间和点赞的自动舆论主源 | 是 | 完整采集或按已声明上限截断后，相关样本不少于 10 条才发布方向 |

历史平台汇总仍保留，但不出现在当前策略调查队列。

## 已完成

- 顶层“舆论监测”导航、监测总览与任务执行页面；
- 策略舆论目标快照：日期、策略版本、有序股票代码、发布时间和内容哈希；
- 每日策略目标最多 10 只，同日同策略版本不可覆盖，修改必须发布新版本；
- 自动任务只读取当天策略目标，每次调查最近 3 个自然日且不重复创建；
- 没有当天策略目标时不建任务、不调用新浪或 DeepSeek；
- 用户可指定单只股票和日期范围创建手动调查，且不加入自动队列；
- 旧热榜未完成任务自动阻塞，成功结果和原始引用继续保留用于审计；
- 新浪股吧股票代码到 `bid` 的公开页面映射；
- 新浪公开主题接口的游标分页；
- 新浪公开回复接口的 `pid` 游标分页；
- 回复页进入用户日期范围之前后立即停止，不为历史总回复数无限翻页；
- 每只股票在用户指定时间窗口内最多采集 300 条，按最新发布时间优先；
- 每个主题最多纳入 50 条回复，防止单一热门主题垄断样本；
- 达到上限的任务按“上限完成”发布，日汇总保存 `sample_capped`（样本已截断）
  和 `sample_limit`（样本上限），前端明确展示，不冒充全量；
- 主题页和回复页均写入任务游标与实时心跳；
- 单只股票每个执行分片最多 3 个网络请求，约 10 秒后主动让出；
- 分片结束立即保存已取得的主题与回复，未完成时保持“采集中”；
- 重股票使用持久化游标等待下一轮，后端按股票轮转到下一只；
- 新浪主题与回复的原始时间、点赞、网址和技术去重键；
- 后端守护线程持有整批队列，浏览器刷新或关闭不会中断；
- 页面只负责启动、停止和读取后端批次状态，不再逐只派发任务；
- 服务意外重启后，再次启动批次会恢复数据库中残留的“执行中”任务；
- 页面提供当前分片完成后停止、股票覆盖进度和完整进度；
- 已有结果股票置顶，并展示利好、利空、争议、中性和无关内容分布；
- 无法稳定完成的受限来源入口及对应公开接口已经移除；
- 新浪主题和回复正文统一由 DeepSeek V4 Pro 批量分类，不再使用关键词机械分类；
- 分类固定为利好、利空、争议、中性、无关五类，并保存模型名、置信度和提示词版本；
- 每批最多 50 条；同一内容哈希、模型和提示词版本不变时直接复用分类结果；
- DeepSeek 日汇总和 1/3/7 日窗口只读取相同提示词版本的内容，旧机械分类
  不再混入新模型计数；
- DeepSeek 单批失败时整批不发布、不推进采集游标，任务转为失败并可安全重试；
- 未配置 DeepSeek API 密钥时不访问上游、不启动批次，页面明确显示未配置；
- 页面可将 DeepSeek API 密钥保存到当前用户的 macOS 钥匙串，也可清除；
- 后端重启后从钥匙串恢复配置，不需要每日重新输入；环境变量配置仍可用；
- 密钥接口只返回配置状态和来源，不回传密钥；批次运行时禁止更换或清除；
- 点赞权重 `1 + ln(1 + 点赞数)`；
- 每个平台独立计算方向，不生成跨平台总分；
- 少于 10 条相关内容或采集未完整时不发布方向，无关内容不进入方向分母；
- 当日、近 3 日、近 7 日窗口，不做时间衰减；
- 三日内更新点赞与删除，三日后冻结；晚到删除只作审计；
- 内容正文不入库，只保存网址、哈希、模型分类、置信度、时间和版本；
- 单并发、至少 5 秒间隔、429 暂停、403 当日停止和连续失败熔断规则；
- 数据库版本 32。

## DeepSeek 配置

优先在“舆论监测 → DeepSeek API 配置”中粘贴密钥。密钥保存到当前用户的
macOS 钥匙串，并只在当前本机后端运行时读取；不写入数据库、浏览器存储、
日志、文档或 Git 仓库。配置一次后，后端重启和每日自动任务会继续使用，
不需要人工重复填写。

也可以继续通过启动后端进程的环境变量提供：

```zsh
read -s "DEEPSEEK_API_KEY?DeepSeek API Key: "
export DEEPSEEK_API_KEY
```

环境变量配置后需要在同一个终端中重新启动后端。不要将真实密钥写入
`.env`、命令历史、聊天或任何可提交文件。

## 仍需注意

- 技术可访问不等于平台永久授权，必须保持低频和来源级熔断；
- 新浪接口结构变化时必须阻止发布，不允许将部分内容标为完整；
- 核心策略当前仍是演示策略，尚未接入真实目标发布者；没有真实策略快照时
  自动队列保持为空，不得用热榜或技术排行冒充；
- 集思录更适合作为锁定候选股后的手动补充，尚未工程接入。
